# Infosys Financial Analysis – MS Excel

## Project Overview

This project analyzes the financial performance of Infosys Limited using consolidated financial data for FY2024–FY2026.

The project was created using Microsoft Excel to analyze financial performance, profitability, liquidity, financial ratios, and future financial estimates.

## Analysis Performed

- Revenue analysis
- Net Profit analysis
- Revenue Growth analysis
- Net Profit Margin
- Current Ratio
- Return on Assets (ROA)
- Return on Equity (ROE)
- Revenue forecasting
- Net Profit forecasting
- Financial performance dashboard

## Financial Forecast

The project includes estimated financial figures for:

- FY2027E
- FY2028E

The revenue forecast is based on the average historical revenue growth rate, while the net profit forecast uses the historical average net profit margin.

## Tools & Skills Used

- Microsoft Excel
- Financial Statement Analysis
- Financial Ratio Analysis
- Excel Formulas
- Data Analysis
- Financial Forecasting
- Data Visualization
- Dashboard Creation

## Company

**Infosys Limited**

**Financial Basis:** Consolidated IFRS  
**Currency:** INR (₹ crore)  
**Historical Period:** FY2024–FY2026

## Key Learning

This project helped develop practical skills in analyzing financial statements, calculating financial ratios, identifying performance trends, creating financial forecasts, and presenting financial information through an Excel dashboard.

## Data Source

Financial data was obtained from the official Infosys investor reports and annual report.

## Disclaimer

Forecast figures are estimates based on historical financial performance and are not official company guidance or projections.
